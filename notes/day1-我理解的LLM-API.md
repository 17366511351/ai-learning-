## 2. Token

**token 是什么？（不要抄"子词单元"这四个字，用你理解的方式说）**

计算机依靠编码识别汉字等语言，我们的提问在传入模型前会先转换成一串能够让模型理解的数字，也就是我们所说的token，是一种子词单元

**中文和英文的 token 换算差异：中文和字符数基本1：1的关系，换算时按照字符数计费，约两个字符记为1 token，1汉字≈0.6-1token;英文则按英语单词计费，1常用词约1 token,1生僻词约2-3 token，1 token≈4字符。**

**我实测的结果（贴数字）：**

| 文本                                               | 字符数 | prompt_tokens  | 比值    |
| ------------------------------------------------ | --- | -------------- | ----- |
| 你好                                               | 2   | 31（起步价30，实际为1） | 2     |
| 你好，请用一句话解释什么事机械学习。                               | 18  | 39（实际为9）       | 2     |
| 你好，请用一句话解释什么事机械学习。*5                             | 90  | 75（实际为45）      | 2     |
| Hello, explain machine learning in one sentence. | 48  | 39（实际为9）       | 5.333 |



**为什么 token 重要（三个理由）：**

1. token是模型计价的依据，我们的花费=输入token\*输入单价+输出token\*输出单价，token消耗越多，成本越高，为了降低成本，我们必须减少token消耗
2. 它是上下文长度的刻度尺。我们模型对话长度一般不是由字符串长度决定，而是由token决定，比如128k长度不是128k字符，而是128k个token
3. token决定响应速度。输入字符越长，模型读取所需时间越长，首字延迟（模型读取完成到吐字所需时间）越长

## 3. 上下文窗口

**上下文窗口 =单次请求内 输入token+输出token 的总上限。**

**它的三个代价，以及各自的原因：**

| 代价 | 为什么                                                                                                     | 我打算怎么应对                                      |
| -- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 贵  | 多轮对话中，由于模型没有记忆功能，会将之前对话记录一并发出，如果有5轮对话，每次对话大概200token，最后总花费是200*（1+2+3+4+5）=3000token，远超分别问五次的1000 token | 丢弃最开始几轮与目前无关的对话，或者将之前对话进行总结，替代之前内容，减少token花费 |
| 慢  | 由于对话轮次的提高，每次输入token都会增加，模型需要的读取时间也会变长，首字延迟随之变长                                                          | 丢弃最开始几轮与目前无关的对话，或者将之前对话进行总结，替代之前内容，减少输入内容长度  |
| 不准 | 随着输入文本的增长，模型会出现对开头和结尾关注，对中间对话内容模糊，会对模型回复造成干扰                                                            | 减少文本输入量，总结聊天记录的重点，让模型抓住重点和疑问进行回复             |

**算一笔账：如果每轮对话 200 token，聊 10 轮累计输入是多少？和单次问答比差几倍？**

200*（1+2+...+10）=5500 token

5500/1000=5.5

## 4. temperature 与 top_p

**temperature 改的是什么？（提示：想想概率分布的形状）**

模型对高概率词的关注度，越低，对高概率词关注越高；越高，低概率词关注会提高

**我实测 temperature 0 vs 1.5 的结果：**

| temperature | 第1次                          | 第2次                               | 第3次                              | 第4次                         | 第5次                            |
| ----------- | ---------------------------- | --------------------------------- | -------------------------------- | --------------------------- | ------------------------------ |
| 0           | 旁听咖啡馆                        | 课间咖啡                              | 课件咖啡                             | 旁听咖啡                        | 旁听咖啡                           |
| 1.5         | 下课见咖啡                        | 课间咖啡                              | 早八咖啡                             | 旁听咖啡                        | 课件咖啡                           |
| 0           | 秋天像一封用凉风和落叶写成的信，提醒人们把热烈慢慢收好。 | 秋天把夏日的喧嚣轻轻折叠，收进一场微凉的细雨里。          | 秋天是风把蝉声收走、让糖炒栗子的香气在清冷空气里慢慢散开的季节。 | 秋天是风把夏天最后一页轻轻翻过，留下满地脆响的凉意。  | 秋天是风把天空吹得高远，落叶替大地轻声翻页的季节。      |
| 1.5         | 秋天是桂花香里掺着微凉的风，把白昼吹短，把思念吹长。   | 秋天是风把天空擦得高远，落叶在脚下轻声翻页，万物收拢起夏日的喧哗。 | 秋天把天空擦得很高，风一过，叶子便学会了告别。          | 秋天是风把叶子轻轻翻到季节下一页时，那一声清冷的叹息。 | 秋天是一封写给大地的信，字里行间都是凉风、果香和落叶的私语。 |

**结论（什么场景该用多少度）：**&#x5206;类、信息抽取、写 SQL、需要完全可复现用0；

知识问答、摘要用0.2-2.5；

日常对话、写作用0.7；

头脑风暴、起名、创意文案用1.0-1.5；

2.0基本不用

**top_p 和 temperature 的区别：top_p调整的是范围，范围外的词不会出现，temperature调整的是对高频率词的关注度，低概率词只是出现概率低，仍会出现。**&#x5982;果说 temperature 是"把分布整体压扁或拉尖"，那 top_p 是"直接把长尾砍掉"。

**为什么建议只调一个：两个一起调不易区分**
