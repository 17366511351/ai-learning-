# 项目一 V0 搭建指南 · 从空目录到能回答问题

> 脚手架里每个文件的 docstring 都写了要做什么。这份指南告诉你**按什么顺序做、每步怎么验收、哪里会坑**。
> 原则：**每一步跑通再走下一步**。全写完再调试 = 地狱。

---

## 第 0 步 · 语料（半天，别跳过）

把 10–50 个文档放进 `data/`（建议南邮培养方案 + 课程大纲 PDF + 几份 Markdown 笔记）。

**验收**：`data/` 里至少 10 个文件，你随手能说出其中 3 个问题的答案（后面要用来出评测题）。

> ⚠️ 别用网上找的干净数据集。真实 PDF 的页眉页脚、断行、表格串行就是你的踩坑素材——面试官问"文档解析遇到什么问题"，网上数据集会让你无话可说。

---

## 第 1 步 · config.py（30 分钟）

填掉 5 个 TODO。Key 从 `.env` 读（`rag-project/` 下建一个，和 ai-learning 的规则一样：绝不提交）。

**验收**：`python -c "from app import config"` 在**任何目录**下都能跑；把 .env 改名后再跑，报错信息是人话。

---

## 第 2 步 · ingest.py 解析（半天）

1. 先做 `parse_markdown`（最干净，建立信心）
2. 再做 `parse_pdf`：pypdf 起步，抽 5 页人工核对
3. `clean()` 写三件事：去页眉页脚、合并断行、压空行

**验收**：抽 10 页和原文对比，乱码/串行 < 2 处。
**记进笔记**：pypdf 在你的语料上具体哪里翻车（表格？多栏？）——这是 V1 换 pdfplumber 对比的伏笔。

> 🕳️ 已知坑：pypdf 对扫描件返回空字符串——在 `parse_pdf` 里检查 `if not text.strip(): continue`，别让它混进语料。

---

## 第 3 步 · chunking.py 切分（2 小时）

先只做 `split_fixed`。核心就是滑动窗口：步长 = size - overlap。

**验收**：拿一个长文档切分，打印前 3 个和最后 1 个 chunk 人工看——边界句子没被腰斩、没有只剩标点的碎片。

---

## 第 4 步 · vectorstore.py 入库与检索（半天）

1. 装依赖：`pip install -r requirements.txt`（首次会下载 bge 模型，约 100MB）
2. 实现 `build_index` + `search`
3. 跑 `python scripts/build_index.py`

**验收**：`index/` 目录有落盘数据；手写 3 个 query 调 `search()`，top-5 结果肉眼看着相关。
**记进笔记**：编码全部 chunk 耗时 ___ 秒，共 ___ 个 chunk。

> 🕳️ 已知坑：① Chroma 的 `add` 要求 id 唯一，重复跑会报错——先 `client.delete_collection` 再建，保证脚本幂等 ② query 编码也要 `normalize_embeddings=True`，和入库时保持一致，否则相似度全错。这个坑踩一次记一辈子。

---

## 第 5 步 · generate.py 生成（半天）

1. `SYSTEM_PROMPT` 我已写好，先别改——V0 求稳
2. 实现 `build_prompt`（编号 + 来源 + 每段截 500 字）
3. 实现 `answer`（同步调用 + try/except）

**验收**：`python -m app.cli "培养方案里毕业要求的总学分是多少"` 返回带 `[1]` 引号的答案。
**同时测 3 个语料里没有的问题**——看模型会不会瞎编（大概率会，别慌，这正是 V2 要修的，先记录现象）。

---

## 第 6 步 · 记录 V0 基线（1 小时，最重要的一步）

出 10 个真实问题跑一遍，填进 `eval/dataset_template.jsonl`，然后记：

| 指标 | 数值 |
|---|---|
| 10 题答对数 | ___ / 10 |
| 平均检索耗时 | ___ s |
| 平均生成耗时 | ___ s |
| 单次 token | 输入 ___ / 输出 ___ |
| 语料外问题编造数 | ___ / 3 |

**这就是 V0 基线。** V1 的混合检索、Rerank 全部和它比。没有这张表，你做的一切优化都是"感觉变好了"，简历上写不出数字。

4. 这个目录以后可以拆成独立仓库（复制出去 `git init` 即可），简历上作为独立项目展示；现在先在 ai-learning 里养着
